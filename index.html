🗺️ 지도 설정

사용할 지도

추천! 지도도 자세하고 장소 검색이 가장 정확해요. 카카오 JavaScript 키가 필요해요 (무료).

  1. developers.kakao.com 로그인 → 내 애플리케이션 → 앱 만들기
  2. 앱의 Web 플랫폼(사이트 도메인)에 아래 주소 등록
  3. 앱 설정에서 카카오맵 사용 설정을 ON
  4. 앱 키 중 JavaScript 키를 복사해서 붙여넣기

네이버 지도 화면을 쓸 수 있어요. 단, 네이버는 브라우저에서 바로 장소 검색을 쓸 수 없어서 검색은 기본 무료 검색으로 돼요. 네이버 클라우드 Maps Client ID가 필요해요.

  1. console.ncloud.com 로그인 (결제수단 등록이 필요할 수 있어요. 무료 사용량 안에서는 요금이 없어요)
  2. Services → Maps → Application 등록 → Dynamic Map 선택
  3. Web 서비스 URL에 아래 주소 등록
  4. 인증 정보의 Client ID를 복사해서 붙여넣기

키 없이 바로 쓰는 무료 지도(OpenStreetMap)예요. 한국 장소 검색은 조금 덜 정확해요.

키는 이 기기 브라우저에만 저장돼요. 가족 모두에게 적용하려면 코드 맨 위 KAKAO_JS_KEY / NAVER_MAP_KEY에 넣어 주세요.
